Explanation:

\begin{itemize}
  \setlength{\itemsep}{0pt}
  \setlength{\parskip}{0pt}
  \item Each categorical embedding has dimension 8.
  \item The hidden layer has width 64.
  \item $B$ denotes the batch size.
  \item $C_j$ counts the known training categories for feature $j$, plus one
    extra category with ID 0 for unknown values.
\end{itemize}

\textbf{Number of trainable parameters:}

Each categorical feature $j$ uses an embedding table with $C_j$ rows and 8
trainable values per row. We add one extra category for unknown category for each feature, which gives:
\[
C_j = \text{number of categories in feature } j + 1.
\]

Calculate $C_j$ for every categorical features:

\begin{center}
\begin{tabular}{lrc}
\toprule
Categorical feature & Number of training categories & $C_j$ calculation\\
\midrule
\texttt{month} & 12 & $C_1=12+1=13$\\
\texttt{town} & 26 & $C_2=26+1=27$\\
\texttt{flat\_model\_type} & 43 & $C_3=43+1=44$\\
\texttt{storey\_range} & 17 & $C_4=17+1=18$\\
\bottomrule
\end{tabular}
\end{center}

Six continuous features: \texttt{dist\_to\_nearest\_stn},
\texttt{dist\_to\_dhoby}, \texttt{degree\_centrality},
\texttt{eigenvector\_centrality}, \texttt{remaining\_lease\_years}, and
\texttt{floor\_area\_sqm}. 

Each contributes one input value. Concatenating the four 8-dimensional embeddings with these six values gives the total input dimension $D$:
\[
  D=4\times8+6=38.
\]
Layer-by-layer trainable parameter counts:

Explanation:

\begin{itemize}
\item Each linear layer includes a weight matrix and a bias vector. 
\item LayerNorm has 64 learnable scale parameters and 64 learnable shift parameters. 
\item Concatenation, ReLU, squeezing, and inverse target standardization add no trainable parameters.
\end{itemize}

\subsection*{(b) Hyperparameter Search}

\begin{itemize}
\item \textbf{Search method:} Ray Tune grid search over 25 combinations: Hidden-layer width $h\in\{16,32,64,128,256\}$ and
embedding dimension $d\in\{2,4,8,12,16\}$ shared by all four categorical features.
\item \textbf{Data split:} Training on 2017--2020 and validation on 2021.
\item \textbf{Training settings:} Seed 42; Adam with learning rate 0.01;
batch size 512; maximum 20 epochs; early-stopping patience 4 and minimum validation RMSE improvement $10^{-4}$.
\item \textbf{Best result:} $h=128$, $d=12$; validation RMSE
59,766.91 SGD at epoch 13. Training stopped at epoch 17 and epoch-13 weights were retained.
\end{itemize}

\subsection*{(e) Discussion}
\begin{itemize}
\item \textbf{Configuration choice:} $(h,d)=(128,12)$ achieved the lowest validation RMSE (59,766.91 SGD), improving on the original $(64,8)$ configuration (63,422.46 SGD) by 5.76\%. The runner-up $(256,2)$ scored 59,926.48 SGD, only 159.58 SGD higher.
\item \textbf{Capacity:} Larger widths and embeddings did not consistently improve validation RMSE. For example, at $h=128$, increasing $d$ from 12 to 16 worsened the best RMSE to 65,599.97 SGD.
\item \textbf{Overfitting evidence:} After epoch 13, training RMSE declined from 31,207.16 to 30,627.12 SGD while validation RMSE rose from 59,766.91 to 69,319.56 SGD by epoch 17, supporting early stopping and indicating overfitting in later epochs.
\item \textbf{Generalisation:} Retraining ended with training RMSE 38,591.78 SGD and test RMSE 90,595.88 SGD. This gap indicates limited generalisation; changes between the training years and 2022 may also contribute.
\end{itemize}

\subsection*{(a) Removing Categorical Embeddings}
\begin{itemize}
\item \textbf{Modification:} All four embedding tables were removed. The first layer changed from $54\to128$ to $6\to128$; LayerNorm, ReLU, and the output layer were retained. Trainable parameters decreased from 8,649 to 1,281.
\item \textbf{Result:} Mean test RMSE increased by 14.15\%, and mean $R^2$ decreased from 0.6543 to 0.5492. RMSE worsened for four of five matched seeds.
\item \textbf{Interpretation:} Categorical inputs provide useful information beyond the continuous features. Mean training RMSE also rose from 38,042.36 to 54,773.49 SGD, consistent with reduced fitting ability. This ablation removes both information and parameters, so their effects cannot be separated.
\end{itemize}
\subsection*{(b) Replacing ReLU with Sigmoid}
\begin{itemize}
\item \textbf{Modification:} Only the hidden activation changed to Sigmoid.
\item \textbf{Result:} Mean test RMSE decreased by 2.58\%, and mean $R^2$ increased to 0.6708. However, RMSE SD increased from 3,652.75 to 7,310.91 SGD; Sigmoid improved RMSE for three of five matched seeds.
\item \textbf{Interpretation:} Sigmoid changes the bounded hidden representation and gradient behaviour while leaving capacity unchanged in parameter count. Mean training RMSE was similar (38,248.06 versus 38,042.36 SGD). Its modest average test improvement and larger seed variation do not establish a reliable advantage over ReLU in this experiment.
\end{itemize}
